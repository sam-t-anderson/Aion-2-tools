Using the raid planner

The Raid Planner runs entirely in your browser — plans are saved on this device. To plan a fight:

  • Add tokens — players (by class), an enemy/boss, raid markers (A/B/C/1/2…) and AoE zones.
  • Plan movement over time — move the timelapse slider to a moment, then drag a token to where it should be then. The planner keyframes that position and interpolates the movement in between, drawing the path. Press ▶ to play it back at 0.5–4×.
  • Party buffs — lay buff windows (name, source, start–end) on the lane under the timeline; the buffs active at the current moment are highlighted.
  • Save & share — plans auto-save locally; export a .a2plan file, copy a share code, or Publish to a server (see below) and Browse others'.

Publishing & browsing plans

Publishing uses a self-hosted aion2calc log server. Enter its address (and an upload key, if it requires one) at the top of the planner page; it is stored only in your browser. Then Publish shares the current plan and gives a link, and Browse plans lists public plans you can open and copy. The desktop app can publish to the same server.

Self-hosting the sharing server

The sharing server (log and plan uploads, community statistics) is a small Python service you run on your own machine — a home box, a VPS, or through Tailscale Funnel. It exposes an open JSON API (/.well-known/a2log.json describes it). See the server repository.
