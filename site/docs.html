Using the raid planner

The Raid Planner runs entirely in your browser — plans are saved on this device. To plan a fight:

  • Add tokens — players (by class), an enemy/boss, raid markers (A/B/C/1/2…) and AoE zones.
  • Plan movement over time — move the timelapse slider to a moment, then drag a token to where it should be then. The planner keyframes that position and interpolates the movement in between, drawing the path. Press ▶ to play it back at 0.5–4×.
  • Party buffs — lay buff windows (name, source, start–end) on the lane under the timeline; the buffs active at the current moment are highlighted.
  • Save & share — plans auto-save locally; export a .a2plan file, copy a share code, or Publish to a server (see below) and Browse others'.

Publishing & browsing plans

Publishing uses a self-hosted aion2calc log server. Enter its address (and an upload key, if it requires one) at the top of the planner page; it is stored only in your browser. Choose Visibility beside Publish plan: Public lists the plan in Browse plans, Unlisted shares by link, and Private requires the secret link. Then Publish plan saves an owner credential in this browser and gives a shared link. Use Update published plan to update the same link or Publish new copy for a separate publication, and Browse plans lists public plans you can open and copy. The desktop app has the same publishing controls and uses its Settings server and upload key. Shared links include Play/Pause, Rewind, playback speed and a timeline scrub bar. Keep a Private ownership backup to restore editing access on another device using Import file. Refresh published plan resolves revision conflicts but replaces local edits; export local changes first. Older plans without saved credentials must be published as a new copy.

Combat logs and comparisons

Logs includes category, boss, build, difficulty and region filters, class DPS distributions and personal record search. World ranks cover public community submissions, not the entire game population. Add missing metadata to local logs in the desktop before uploading. Compare multiple runs with explicit same-class player selection; recorded DPS is not adjusted for gear.
