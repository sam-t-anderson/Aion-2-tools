# Templar PvP comparison example

Open this build in Planner to view skills, specialties, Daevanion nodes and hotbar. The frozen common loadout uses 383 Skill, 300 Stigma and 416 crystal Daevanion points, and up to 70 bonus skill levels from gear rolls and arcana cards, at most 9 on one skill (the build places 56): the highest the community server's contributors had reported for the class on 5 November 2026. These are reported totals, not verified progression maxima.

Weighted modeled DPS: **15,427.2**. Sustained player-target damage (180 seconds) and burst (30 seconds) each contribute 50%. One allocation is searched for each and the stronger is refined on the weighted objective, each search with one optimization iteration and calibration disabled; the best of the three is kept. Scores compare only the same class, mode and scoring scope.

This stationary damage proxy does not validate PvP coefficients, dedicated progression, defensive skill use, crowd control, movement, opponent matchups or win rates. It is not proof of a global optimum. Personal gear, Genus and HP/skill reserves are excluded from the common comparison.
