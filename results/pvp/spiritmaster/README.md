# Spiritmaster PvP comparison example

Open this build in Planner to view skills, specialties, Daevanion nodes and hotbar. The frozen common loadout uses 347 Skill, 50 Stigma and 305 crystal Daevanion points: the highest the community server's contributors had reported for the class on 5 November 2026. These are reported totals, not verified progression maxima.

Weighted modeled DPS: **48,410.1**. Sustained player-target damage (180 seconds) and burst (30 seconds) each contribute 50%. One allocation is searched for each and the stronger is refined on the weighted objective, each search with one optimization iteration and calibration disabled; the best of the three is kept. Scores compare only the same class, mode and scoring scope.

This stationary damage proxy does not validate PvP coefficients, dedicated progression, defensive skill use, crowd control, movement, opponent matchups or win rates. It is not proof of a global optimum. Personal gear, Genus and HP/skill reserves are excluded from the common comparison.
