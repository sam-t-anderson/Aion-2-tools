# Cleric PvP comparison example

Open this build in Planner to view skills, specialties, Daevanion nodes and hotbar. The frozen common loadout uses 203 Skill, 30 Stigma and 360 crystal Daevanion points; these are comparison resources, not progression maxima.

Weighted modeled DPS: **5,486.9**. Sustained player-target damage (180 seconds) and burst (30 seconds) each contribute 50%. The selected allocation is the stronger of one sustained and one burst search, each with one optimization iteration and calibration disabled. Scores compare only the same class, mode and scoring scope.

This stationary damage proxy does not validate PvP coefficients, dedicated progression, defensive skill use, crowd control, movement, opponent matchups or win rates. It is not proof of a global optimum. Personal gear, Genus and HP/skill reserves are excluded from the common comparison.
