INSTALL

  • Windows: run the installer (aion2calc-setup-….exe). It needs no administrator rights and adds a Start menu shortcut. If SmartScreen says "Windows protected your PC", choose More info → Run anyway (the app is not code-signed).
  • Windows portable: unzip anywhere and run aion2calc.exe.
  • macOS: unzip, then right-click aion2calc.app → Open the first time (the app is not notarized).
  • Linux: unpack and run aion2calc/aion2calc.

The app opens in its own window. Your data stays on your computer.
